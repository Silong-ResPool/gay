## 📋 整体介绍

巳泷资源库是一款集影视、游戏、音乐、动漫、小说于一体的网络资源导航应用。采用现代化毛玻璃 UI 设计，内置智能管家「玉珩」，多端同源、动态更新。

### ✨ 核心特性

* 🎯 **资源丰富**：全品类资源覆盖，站点数据按分类拆分，按需加载
* 🎨 **界面美观**：毛玻璃设计，日间全蓝白 / 夜间紫罗兰双主题（无黄昏模式）
* 🔍 **智能搜索**：多引擎实时定位，支持历史记录
* 🎵 **媒体音乐**：全网免费音乐搜索与歌单管理
* 🎮 **游戏中心**：Flash 与独立游戏，内置 Ruffle 播放器
* 🎬 **影视乐园**：多源接口 + 每日远程清单 + 手动添加，卡片网格展示
* 🤖 **智能管家玉珩**：聊天、语音朗读、群聊、成员资料、关系绑定
* 🧩 **Live2D**：三种内核（推荐 / 星标最高 / 自动），支持上传 zip / lpk / wpk 模型
* 🖥️ **全平台**：Android、HarmonyOS、Windows 原生壳（单文件 EXE）、iOS 与网页版同源
* 🌐 **动态更新**：网页内容实时更新，无需打包发布

## 🆕 v8.0.4 新增与优化

### ⚡ 性能

* 首页移除内嵌 9.2MB 桌宠视频，改为外链懒加载，**index.html 由 9218KB 降至 229KB**，首屏打开速度提升约 40 倍
* 桌宠视频 `preload="none"`，仅在打开小窗时播放，正常浏览不占带宽
* 站点数据按分类拆分成独立文件，避免一次性拉取全部资源
* 失败兜底场景资源改为按需加载，正常浏览不加载 10MB 素材

### 🤖 AI 与管家

* 新增 NVIDIA 内置接口（DeepSeek 模型，4 个隐藏密钥轮换）
* 两个内置 API 自动探测（并行 ping，6 秒），可用优先 DeepSeek/NVIDIA，失败自动回落到原有 API
* 所有 AI 请求加入单次超时（18s / 15s），不再出现"一直转圈"
* 新增手动切换按钮：原有 API / NVIDIA / 自动回落
* 模型列表随输入自动刷新，保存配置后立即重新拉取
* 全局「我的设定 / 关系绑定」写入系统提示词，姐妹 / 恋人 / 兄弟 / 父子 / 母女 / 母子 / 父女 / 主仆 / 自定义
* 群聊读取全局设定，新增成员资料页，群聊内置默认 API

### 🎬 影视乐园

* 布局重构为卡片网格，海报加载更整齐
* 多源接口 + 每日远程清单 + 手动添加接口
* 综合资源首屏不足 8 条时自动切换同分类源，不再只有 4 张海报
* 修复接口跨域（CORS）导致的 "Failed to fetch"

### 🧩 Live2D

* 弃用官方 lpk/web.html，改用第三方查看器
* 三种内核：推荐 / 星标最高 / 自动；修复模型只显示碎片的问题（改用官方 Cubism Core）
* 支持上传 .zip / .lpk / .wpk 模型包，新增解析中 / 载入成功 / 解析失败提示

### 🖥️ 桌面端与主题

* Windows 原生壳（WinForms + WebView2），单文件 EXE，底部五项导航（返回/前进、刷新、首页、标签页、设置），图标与安卓一致
* 恢复小窗「聊天气泡」纯图标入口，点击直达聊天
* 聊天页小人改为透明通道视频，位置再次下移
* 日间全蓝白（含小窗、侧栏、悬浮球），夜间紫罗兰，**彻底移除黄昏模式**
