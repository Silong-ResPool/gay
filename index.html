搜索设置
数据通道默认「自动」：优先本地代理，失败再切公共代理与直连。全部失败时会提示。
启用的搜索引擎网页支持 Bing / Yandex / 微软；视频支持 B 站 / Yandex；图片支持 Bing / Yandex；磁力支持 TPB。
磁力打开方式默认内置 Web 解析；无法解析时自动切换为调用本地下载工具。
国际源代理出口可选，用于 Yandex / Google / DuckDuckGo 等。支持 HTTP / SOCKS5，例如 http://127.0.0.1:7890 或 socks5://127.0.0.1:7891；留空会自动尝试 7890 / 10809 / 7891 / 1080。
